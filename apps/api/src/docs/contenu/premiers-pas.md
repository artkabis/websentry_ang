WebSentry analyse un site page par page et rend un score de qualité, accompagné
de la liste des points à corriger. L'outil ne remplace pas un audit humain : il
le prépare, en signalant ce qui se vérifie automatiquement.

## Lancer une première analyse

1. Ouvrez l'écran **Analyse** depuis la barre de navigation.
2. Collez l'adresse d'une page, puis lancez l'analyse.
3. Le rapport s'affiche dès que la page a été récupérée et examinée.

Le rapport commence par les **corrections prioritaires** : ce sont celles dont
l'effet sur le score est le plus fort. Le détail complet reste disponible juste
en dessous, replié par défaut.

> Note: une analyse porte sur UNE page. Pour un site entier, passez par
> l'analyse par lot ou par le sitemap.

## Comprendre le score

Le score global est une moyenne pondérée des critères actifs. Deux réglages le
font varier, et ils sont tous deux visibles dans le profil de la gamme :

- les **critères actifs** — un critère désactivé ne compte pas ;
- les **pondérations** — un critère peut peser plus qu'un autre.

Un même site analysé avec deux profils différents obtient donc deux scores
différents. C'est voulu : un site vitrine et une boutique n'ont pas les mêmes
exigences.

> Attention: comparer deux scans n'a de sens que si le profil n'a pas changé
> entre les deux. L'historique conserve le profil utilisé pour chaque scan.
